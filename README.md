# Lumpy Skin Disease Prediction using Machine Learning

## Project Overview
This project uses Machine Learning algorithms to predict Lumpy Skin Disease using the given dataset.  
The following algorithms are implemented and evaluated:

- Linear Regression
- Logistic Regression
- Decision Tree
- Random Forest

Performance metrics such as Accuracy, Precision, Recall, F1-Score, Mean Squared Error, and R2 Score are calculated.
